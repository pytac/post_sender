# POST请求发送器

## 简介

POST请求发送器是一个命令行工具，用于向指定的URL发送POST请求。它支持从JSON文件中读取请求负载，并具有自动协议补全和HTTPS到HTTP的故障转移功能。

## 功能特性

- **自动协议补全**: 自动为URL添加`http://`或`https://`前缀，默认优先使用HTTPS
- **HTTPS故障转移**: 当HTTPS连接失败时，自动尝试使用HTTP连接
- **JSON文件支持**: 从外部JSON文件读取请求负载数据
- **彩色终端界面**: 使用Blessed库提供美观的彩色终端界面
- **错误处理**: 完善的错误处理和用户友好的错误提示

## 颜色编码

- **紫色**: 输入提示语和程序标题
- **红色**: 错误提示信息
- **黄色**: 信息提示（如连接状态、尝试信息等）
- **绿色**: 响应结果标题和状态信息
- **白色**: 实际响应内容

## 安装依赖

在使用此工具前，请确保安装以下Python包：

```bash
pip install requests blessed
```

## 使用方法

### 1. 启动程序

运行脚本后，您将看到欢迎信息：

```
=== POST请求发送器 ===
此程序将向您提供的URL发送POST请求。
输入 'quit' 或 'exit' 退出程序
```

### 2. 输入URL

程序会提示您输入目标URL：

```
请输入目标URL (输入 'quit' 或 'exit' 退出): 
```

您可以输入不带协议的URL（如 `example.com/api`），程序会自动补全为 `https://example.com/api`。

### 3. 输入JSON文件路径

程序会要求您提供包含POST请求负载的JSON文件路径：

```
请输入JSON文件路径: 
```

JSON文件应该包含有效的JSON格式数据，例如：

```json
{
  "name": "John Doe",
  "email": "john@example.com",
  "message": "Hello World"
}
```

### 4. 查看结果

程序会显示发送的请求信息和服务器响应：

- 请求状态
- HTTP状态码
- 响应头信息
- 响应内容

## 故障转移机制

当您输入的URL以HTTPS形式存在但无法连接时，程序会：

1. 首先尝试HTTPS连接
2. 如果遇到SSL错误，会显示错误信息
3. 自动尝试使用HTTP协议重新连接
4. 显示连接状态信息

## 退出程序

在任何输入提示处输入 `quit` 或 `exit` 即可退出程序。

## 注意事项

- 确保JSON文件格式正确
- 确保目标服务器可访问
- 对于本地开发环境，可能需要使用HTTP而不是HTTPS
- 程序设置了30秒的请求超时时间
